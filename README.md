# ✈️ 飞机大战 - Aircraft War

基于 Java Swing 开发的经典飞机大战游戏，具备完整的游戏逻辑、多难度选择、得分排行榜、道具系统、音效控制和多种设计模式实践。

## 📋 项目简介

本项目是哈尔滨工业大学（深圳）《软件构造》课程的综合性实验项目，实现了一个功能完整的飞机大战游戏。玩家控制英雄机躲避并击落敌机，通过拾取道具获得增益效果，挑战不同难度等级下的高分记录。

## 🎮 游戏功能

### 核心玩法
- 鼠标控制英雄机移动，自动发射子弹
- 击落不同类型敌机获得分数
- 收集道具获得临时或永久增益
- 达到指定分数后召唤 Boss 敌机

### 游戏难度
| 难度 | 特点 |
|------|------|
| 简单 | 敌机数量少、生成慢、英雄血量高、无 Boss |
| 普通 | 正常难度，随时间提升敌机生成速度 |
| 困难 | 敌机数量多、速度快、英雄血量低、Boss血量递增 |

### 道具系统
| 道具 | 效果 |
|------|------|
| 加血道具 | 恢复英雄机生命值 |
| 火力道具 | 临时切换为扇形散射弹道 |
| 超级火力道具 | 临时切换为 360° 环射弹道 |
| 炸弹道具 | 清除所有在场敌机 |
| 冰冻道具 | 冻结敌机，不同敌机效果各异 |

### 排行榜系统
- 按难度分类存储得分记录（JSON 格式）
- 支持查看前 10 名排行榜
- 支持删除任意历史记录
- 游戏结束后自动保存本局得分

### 音效系统
- 游戏背景音乐循环播放
- 击中敌机、拾取道具、炸弹爆炸音效
- Boss 出场切换专属音乐

## 🏗️ 技术架构

### 开发环境
| 项目 | 版本 |
|------|------|
| JDK | OpenJDK 25 |
| IDE | IntelliJ IDEA 2025.3 |
| 构建 | 直接编译（非 Maven） |

### 设计模式应用
| 模式 | 应用场景 |
|------|---------|
| 单例模式 | 英雄机（HeroAircraft）、音频管理器 |
| 简单工厂模式 | 道具创建（PropFactory） |
| 工厂方法模式 | 敌机创建（EnemyFactory + 具体工厂） |
| 策略模式 | 弹道发射逻辑（直线、扇形、环射） |
| 观察者模式 | 炸弹/冰冻道具生效通知 |
| 模板模式 | 游戏难度控制（AbstractGame + 难度子类） |
| DAO 模式 | 得分记录持久化存储 |

### 项目结构
AircraftWar/
├── src/edu/hitsz/
│ ├── application/ # 游戏主类（Game, Main）
│ ├── aircraft/ # 飞机类（英雄机、各类敌机）
│ ├── bullet/ # 子弹类
│ ├── prop/ # 道具类
│ ├── factory/ # 敌机工厂（工厂方法模式）
│ ├── strategypattern/ # 射击策略（策略模式）
│ ├── observer/ # 观察者模式（道具通知）
│ ├── template/ # 模板模式（游戏难度）
│ ├── DAO/ # 数据访问对象模式
│ ├── manager/ # 管理器（音频、Boss）
│ └── ui/ # Swing 界面（难度选择、排行榜）
├── images/ # 游戏图片资源
├── audios/ # 音效文件（WAV）
├── scores/ # 得分数据（JSON）
└── uml/ # UML 类图（PlantUML）

## 🚀 运行说明

### 前置要求
- JDK 11 或更高版本
- 项目依赖：Gson 2.10.1（已包含在 `lib/` 目录）

### 运行步骤
1. 克隆仓库到本地
   bash：
   git clone https://github.com/RunnerHitsz/AircraftWar.git
2. 使用 IntelliJ IDEA 打开项目
3. 配置 SDK：File → Project Structure → SDK → 选择 JDK 25
4. 运行 src/edu/hitsz/application/Main.java
